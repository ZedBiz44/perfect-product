# Idea hopper

[Decision guide](../current-direction.md) · [Ingredient register](../ingredients.md)

Salvageable ideas and possible later layers. **Hopper means unapproved and outside the current core candidate.** It does not undo a recorded rejection.

| Idea | What to retain | What remains unresolved |
| --- | --- | --- |
| [Door Opener](door-opener.md) | A useful prospect-facing win that helps an agency get clients | Difference from existing free audits; willingness to pay |
| [Think and Grow Rich](think-and-grow-rich.md) | Evidence about what actually works across businesses | Real outcome data and repeat usefulness |
| [Mary's shelf](marys-shelf.md) | A reusable catalog and distribution through existing owners | A specific wanted item; avoid the rejected generic Wholesale Shelf |
| [Sponsor layer](sponsor-layer.md) | A possible later payer for a useful weekly item | Sponsor demand without creating a coordinated service |

Other held ideas, dead proposals, and reusable pieces are listed in the ingredient register. Revisit an idea only with a specific new piece of evidence; preserve the reason it was parked.

## Offer snapshot
- Buyer/payer: Existing Shovel owners as an add-on (illustrative).
- Offer: Stickiness features inside the Shovel: progress tracking, completion records, data-driven encouragement; optional leaderboard.
- Delivery: Software features within the host product; customers manage members.
- Price hypothesis (working assumption, not verified willingness-to-pay): Bundled inside the base subscription (unvalidated).
- Repeat mechanism: Feature use recurs with the base subscription; retention features earn their keep through reduced churn rather than a separate price.
- Founder's role: Weekly selection shared with the core edition; within the same 1-3 hrs/week.
- Primary satisfaction shape: Six Pack of Beer Desire (supporting: plus Trophy data for the leaderboard aspect)

## Material assumptions (labelled)
- A-host: assessed as an add-on to the Shovel (product 01); standalone value is not assumed.
- A-data: progress data reports effort and does not invent results.
- A-price: bundled; no separate price tested.

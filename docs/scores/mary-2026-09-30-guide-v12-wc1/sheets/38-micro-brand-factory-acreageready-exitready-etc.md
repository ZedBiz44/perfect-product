## Offer snapshot
- Buyer/payer: Niche buyers per brand (illustrative: rural property buyers via AcreageReady).
- Offer: A factory producing micro-brands, each a finished one-job box for a niche buyer (AcreageReady, ExitReady, etc.); per-brand price; shared factory methods.
- Delivery: Digital boxes per brand; operator runs the factory; buyers use the box for the defined job.
- Price hypothesis (working assumption, not verified willingness-to-pay): Per-brand working price (unvalidated).
- Repeat mechanism: Each brand is a stand-alone purchase; the factory earns repeat through additional brands bought for additional jobs.
- Founder's role: Sets quality standards; 2-4 hrs/week total (capped).
- Primary satisfaction shape: Tool in the hand (supporting: via the example lane (AcreageReady as the named example: a finished buyer-system box))

## Material assumptions (labelled)
- A-brand: each brand is a genuine one-job box for a real niche job.
- A-frag: fragmentation across brands is manageable.
- A-price: unvalidated.

## Offer snapshot
- Buyer/payer: Operators wanting finished events without the production work (event package); organizations wanting ongoing benefit production (retainer).
- Offer: Benefits factory: one finished event-in-a-box per quarter plus an optional ongoing benefit-production retainer.
- Delivery: Digital event packages; operator produces; buyers run their events.
- Price hypothesis (working assumption, not verified willingness-to-pay): Per-event package price + retainer (unvalidated).
- Repeat mechanism: Quarterly events recur, and the retainer layer supplies ongoing revenue between events.
- Founder's role: Sets production standards; 0-2 hrs/week.
- Primary satisfaction shape: Six Pack of Beer Desire (supporting: plus Event Excitement for the event package)

## Material assumptions (labelled)
- A-ev: the event package is the concrete anchor; the retainer is the recurring layer.
- A-run: buyers run their own events competently from the package.
- A-price: unvalidated.

## Product and assumptions

- **Buyer and payer:** A GoHighLevel (GHL) agency or experienced GHL consultant is both intended buyer and payer. The archive says this buyer was expressly ruled out for Jack; it is not treated as an approved customer segment.
- **Promise and delivery:** Install one ready-to-use lead-response system so each new lead gets an immediate response, clear next step, and follow-up path without rebuilding a client account. Delivery is a downloadable workflow/snapshot, install video, setup and testing checklists, copy pack, and approval-mode rules; support is one consolidated written setup question per buyer in a weekly batch, with no account access, custom mapping, imports, calls, moderation, or bespoke troubleshooting.
- **Price hypothesis and repeat-payment mechanism:** $249 founding one-time price (the archive specifies the first ten buyers), then $99/year for optional updates after the first year. The entry also lists related kits at $79–$299. These are unvalidated hypotheses, not verified market pricing or renewals. The repeat rationale is continued compatibility/update value for a platform-dependent workflow.
- **Founder role:** In the proposed five-hour model, Jack would maintain and test the release, batch written support, do direct outreach or partner follow-up, improve common install failures, and review results. In the documented correction, Jack rejects the GHL market: GHL is retained only as behind-the-scenes infrastructure, not a market, credibility base, or standalone business.
- **Primary and supporting satisfaction shapes:** **Primary: Tool in the Hand** — a capable agency installs a fixed lead-response tool. **Supporting shapes: none explicitly specified.**
- **Material assumptions:**
  - **A1 — Buyer capability (assumption):** The payer is already technically competent with GHL and can follow the documented installation and test path without custom account work.
  - **A2 — Compatibility (assumption):** A current GHL account can receive the workflow/snapshot and deliver the described lead response without a buyer-specific integration, data, or compliance project.
  - **A3 — Renewal value (assumption):** Platform changes or useful improvements recur often enough that some buyers would value optional $99 annual updates.
  - **A4 — Buyer value (assumption):** An agency can recognize avoided lead-response failure and/or client resale value sufficient to make the stated founding price plausible. No purchase, retention, or outcome evidence is claimed.
  - **A5 — Operating boundary (assumption):** The stated support and clean-demo limits can be maintained as buyer count rises; the archived test was withdrawn, so this is not observed.

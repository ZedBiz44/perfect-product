Grok added Tool in the hand, Trophy, and Belonging without hosting. Bars 8–9 cover a natural route to buyers and ease of getting value. Bar 10, Newton's Rule, covers advantages from scale. References synchronized September 30, 2026.

This page maps satisfaction shapes to the Perfect Product bars and scorecard traits. Ideas below are proposals for the hopper, not approved products. The shape tables are illustrative design notes, not completed U/0/1/2 assessments. Use the [current rubric](perfect-product-rubric.md) and [scores ledger](../scores/README.md) for evidence-based candidate scores.

## How to read this

Each shape must still clear the bars:

1. Pays more than once
2. Build once, sell many times, with a worthwhile margin after reaching, serving, and supporting the customer
3. Creates Gold (ownable, transferable assets that appreciate and can be acquired)
4. Can run without Jack as the daily center (including no community-host treadmill)
5. Meets a primary satisfaction shape below; supporting shapes are allowed
6. No Brainer (obvious value, existing spend or measurable pain, and a small price relative to the payoff)
7. C3PO (AI performs core production, delivery, or support; people handle verification, judgment, and exceptions)
8. A natural route to buyers (repeatable access without constant personal selling)
9. Easy to get the value (clear, manageable effort and timing that fit the promised satisfaction)
10. Newton's Rule (growth creates an advantage through purchasing power, reusable production, distribution, lower unit costs, or network/data effects)

Plus the practical filters from [current-direction.md](../current-direction.md): no client retainers as the core, GHL/AI as infrastructure not the product, founder-fit, and a real buyer with budget.

## 1. Six Pack of Beer Desire (instant thirst)

**What satisfaction feels like:** Grab it, crack it, thirst gone before you're home.

**Six-pack version:** Second beer today, four more through the week, rebuy next week.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Strong if subscription or weekly rebuy |
| Build once, sell many | Strong (same drop format, new unit each week) |
| Sellable asset | Subscriber list + archive |
| Runs without founder | Strong if production is systematized |
| No host treadmill | Strong if value is the unit, not Jack's presence |
| Low-friction first yes | Strong |
| Deletes a bottleneck | Only if the unit removes a real job, not "nice tip" |
| Own distribution | Weak unless sold through an existing audience owner |

**ZedBiz example:** A weekly member-action unit for audience owners (one mission + comment-word + homework), sold as a cheap subscription. Not a tip vault. Closest living candidate: [Shovel](../concepts/shovel-your-biz-shit.md), if framed as the owner's money problem (empty room / lurkers / churn), not PLR.

**Risk:** Fails the beer test when framed as content. Competes with free AI and $27 PLR.

## 2. Coat of paint (transformational reveal)

**What satisfaction feels like:** Cover the old, step back, it looks new. You show it off. Not weekly; buy again when life creates a fresh surface.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Repeat over years + niche editions + agency resale |
| Build once, sell many | Strong (template refresh, niche skins) |
| Sellable asset | Catalog of niche "new coats" + buyer list |
| Runs without founder | Strong if delivery is self-serve or agency-installed |
| No host treadmill | Strong |
| Low-friction first yes | Medium (higher ticket than beer; still one clear box) |
| Deletes a bottleneck | Strong ("make it look current" without hiring a full rebrand) |
| Own distribution | Strong via agencies, chambers, franchise HQs |

**ZedBiz example:** "New Coat" local-business refresh kits at life moments (new location, new offer, post-renovation, slow-season reset). One finished package the client can photograph and put in the window. Sold to agencies and chambers who resell or include it. GHL only delivers assets.

**Risk:** Looks like custom design if scope creeps. Must stay a fixed kit, not a project.

## 3. Event Excitement (anticipation + peak + afterglow)

**What satisfaction feels like:** Tickets early, look forward for a month, peak night, talk about it for two weeks, photos. Level Up is yearly; a tour is recurring; an auditorium hosts many events.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Ticket cycles, seasonal nights, multi-location reuse |
| Build once, sell many | Strong if Jack supplies the night-in-a-box, not the room |
| Sellable asset | Event catalog + organizer list |
| Runs without founder | **Only if Jack never hosts** |
| No host treadmill | Hard fail if Jack is on stage every time; pass if product is the kit |
| Low-friction first yes | Medium (date-bound purchase) |
| Deletes a bottleneck | Strong for owners who need a member night and hate inventing it |
| Own distribution | Strong through group owners who already have members |

**ZedBiz example:** "Member Night in a Box" for Skool/Facebook/chamber owners: theme, mission, guest prompt, photo-worthy moment, run-of-show. Owner or their staff runs it. Jack never shows up. Sell per night or seasonal pack.

**Risk:** Drift into Jack hosting. Keep founder off the stage as a hard rule.

## 4. Harvest Gala (seasonal pile of results)

**What satisfaction feels like:** After a season of work, a bin full of results. Farmers know this. Year-end books, 40 booked jobs, tax refund.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Every season, every year |
| Build once, sell many | Strong (one seasonal campaign, many agencies/clients) |
| Sellable asset | Seasonal catalog + results library |
| Runs without founder | Strong if agencies run it |
| No host treadmill | Strong |
| Low-friction first yes | Medium (seasonal buying window) |
| Deletes a bottleneck | Strong ("fill the calendar this season") |
| Own distribution | Agency and association channels |

**ZedBiz example:** Seasonal harvest campaigns sold to agencies once per season (winter reactivation, spring open, back-to-school). Niche editions. Agency marks up to clients. Results photo / case numbers are the harvest.

**Risk:** Collapses into "Cash This Week" / generic reactivation unless the season + niche + promised harvest are specific.

## 5. Tool in the hand (competence)

**What satisfaction feels like:** First use makes you capable. Stream Deck, Carex Hip Kit, OnlineJobs.ph.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Refills, upgrades, niche editions, seat licenses |
| Build once, sell many | Strongest bar fit |
| Sellable asset | Product + brand + install base |
| Runs without founder | Strong |
| No host treadmill | Strong |
| Low-friction first yes | Strong if priced like a tool, not a program |
| Deletes a bottleneck | Core promise |
| Own distribution | Via agencies, app marketplaces, or niche Facebook groups |

**ZedBiz example:** One-job local marketing tools sold as products: Google profile fixer, review-ask kit, reactivation dialer kit. Designed from Jack's 25 years. Optional niche packs as the ladder. Not coaching.

**Risk:** Becomes "another GHL snapshot" if positioned as software for agencies instead of a finished job tool for a named moment.

## 6. Trophy (displayable status)

**What satisfaction feels like:** Something you hang or show. Awards, plaques, scored certificates, Level Up recognition.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Annual recert, agency multi-client seats |
| Build once, sell many | Strong (scoring system + badge) |
| Sellable asset | Scoring IP + dataset (Think and Grow Rich layer) |
| Runs without founder | Strong once rubric is fixed |
| No host treadmill | Strong |
| Low-friction first yes | Medium |
| Deletes a bottleneck | Medium (status more than skill) |
| Own distribution | Agencies/chambers hand it to clients |

**ZedBiz example:** A scored "Local Presence Score" or small-business marketing certificate. Agency or chamber administers it. Client hangs it. Benchmark data (Think and Grow Rich) feeds scoring later as stickiness, not the main product.

**Risk:** Empty badge with no earned standard. Must be grounded in real criteria or it becomes a joke.

## 7. Belonging without hosting (structure, not mayor)

**What satisfaction feels like:** "People like me are here," without the founder living in the comments. The product is the operating system.

| Bar / trait | Fit |
| --- | --- |
| Pays more than once | Membership / seat licenses |
| Build once, sell many | Strong if selling the OS to many owners |
| Sellable asset | Playbooks + prompts + scoreboard IP |
| Runs without founder | **Only if Jack is not the mayor** |
| No host treadmill | Pass only as B2B2C structure sold to owners; fail if Jack hosts |
| Low-friction first yes | Medium |
| Deletes a bottleneck | Strong for owners who want peer energy without inventing it |
| Own distribution | Sell to owners who already have members |

**ZedBiz example:** Peer-circle operating system (prompts, scoreboard, missions) licensed to group owners. Their staff or VA runs the room. Jack sells the system. Aligns with rejected "Community Without the Host" lessons: VA as social engine already failed when Jack still owned the community; here the *owner* owns the community and buys the OS.

**Risk:** Soft return to hosting. Hard rule: Jack never runs a member community as the product.

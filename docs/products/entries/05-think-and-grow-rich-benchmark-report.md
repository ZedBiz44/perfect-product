# 5. Think and Grow Rich (benchmark report)

[Index](../README.md) · [Rubric](../../framework/perfect-product-rubric.md)

- **Tier:** mid
- **Shape:** Trophy (hypothesis); Creates Gold is a separate bar, not a satisfaction shape
- **Type:** ingredient

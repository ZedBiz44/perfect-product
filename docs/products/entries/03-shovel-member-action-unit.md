# 3. Shovel member-action unit

[Index](../README.md) · [Rubric](../../framework/perfect-product-rubric.md)

- **Name:** Shovel member-action unit (mission / comment-word / homework)
- **Idea:** Reframe the weekly drop as one member-action unit (mission + comment-a-word + homework) instead of a tip vault.
- **How:** Same weekly cadence as Shovel; success measured by members completing an action and owners reusing next unit.
- **Buyer:** Paid community owners whose pain is lurkers / empty room / churn.
- **Price:** Same band as Shovel (~$29–$49/mo).
- **Tier:** mid
- **Shape:** Six Pack of Beer Desire
- **Type:** format variant
- **Status:** exploration

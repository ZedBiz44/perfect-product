# 6. Mary's one-job shelf

[Index](../README.md) · [Rubric](../../framework/perfect-product-rubric.md)

- **Name:** Mary's one-job shelf ("build the shelf, not the box")
- **Idea:** A tiny ruthless catalog of one-job kits labeled by job (not guru), self-serve, building a sellable product line.
- **How:** Start with a few real one-job kits ($29–79); add kits only after demand; shelf = catalog + customer list + transaction history.
- **Buyer:** Operators who buy at midnight (blunt buyers); later agencies/chambers as distributors — distinct from dead Wholesale Shelf contents.
- **Price:** $29–$79 per kit.
- **Tier:** mid
- **Shape:** Tool in the hand
- **Status:** hopper
- **Sources:** `docs/hopper/marys-shelf.md`, `docs/perspectives/mary.md`
- **Notes:** Structure retained; generic Wholesale Shelf remains dead.

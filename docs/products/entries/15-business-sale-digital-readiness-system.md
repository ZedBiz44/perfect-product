# 15. Business-sale digital-readiness system

[Index](../README.md) · [Rubric](../../framework/perfect-product-rubric.md)

- **Name:** Digital Sale File Starter System
- **Idea:** Broker-branded digital-readiness system for owners preparing a business for sale.
- **How:** Seller workbook, asset inventory, ops/key-person prompts, broker intake, non-legal transition checklist; fixed-scope licence.
- **Buyer:** Business brokers, succession advisers, accountants, lenders.
- **Price:** Founding licence ~$497–$2,000.
- **Tier:** high
- **Shape:** Tool in the hand
- **Status:** hopper
- **Sources:** `docs/research/commercial-proof-first-screen.md`, `docs/ingredients.md`
- **Notes:** Generic seller guides rejected; need broker gap + paid commitment first.

# 14. Rural property buyer system

[Index](../README.md) · [Rubric](../../framework/perfect-product-rubric.md)

- **Name:** Rural Property Pre-Offer Reality Check (channel-owner system)
- **Idea:** Region-specific rural/acreage pre-offer system sold to agents/lenders who already meet buyers at the moment of need.
- **How:** Lead-capture page, property-visit scorecard, professional-question list, auto follow-up; fixed no-customization founding licence.
- **Buyer:** Rural real-estate agents, land lenders, close partners (payers); end buyers get the worksheet.
- **Price:** Founding licence ~$497–$2,000 + possible ~$97/mo.
- **Tier:** high
- **Shape:** Tool in the hand
- **Status:** hopper
- **Sources:** `docs/research/commercial-proof-first-screen.md`, `docs/ingredients.md`
- **Notes:** Generic D2C acreage guides rejected; need paying channel owner first.
